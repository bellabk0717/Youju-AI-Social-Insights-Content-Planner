# Third-party notes

This project independently implements a small Xiaohongshu writing-analysis schema inspired by the `xiaohongshu-ingest` skill in [chubbyguan/chubbyskills](https://github.com/chubbyguan/chubbyskills/tree/main/xiaohongshu-ingest): audience, scene, need/pain point, emotion, title hook, and body structure. The following repositories were reviewed for product research but no source code or protected text was copied:

- [Xiangyu-CAS/xiaohongshu-ops-skill](https://github.com/Xiangyu-CAS/xiaohongshu-ops-skill) — no license was found during review.
- [sammyteng/xhs-producer](https://github.com/sammyteng/xhs-producer) — marked All Rights Reserved.
- [c456-com/skills](https://github.com/c456-com/skills/tree/main/short-viral-content) — numerical performance claims were not adopted because supporting evidence was not provided in the skill.
